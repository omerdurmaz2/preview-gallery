# Phase log

Every phase of the plugin in order. Commit subjects carry the phase and task: `[PG13-4] - …`. Phase 1 predates the
numbering scheme, so its commits read `[PG-n]`. Commit bodies explain the why:
`git log --reverse --format='%h %s%n%b' --grep='^\[PG13-'`.

- Ranges are `first..last` short hashes.
- "Docs" points at the area doc in [`features/`](features) that tells the current story.
- Specs live under [`../superpowers/specs`](../superpowers/specs) and plans under [`../superpowers/plans`](../superpowers/plans).
